AI Laboratory Programs 
## Results / Output
The Water Jug Problem was implemented using Breadth-First Search (BFS).
The algorithm explores possible states and finds a sequence of operations
to reach the target quantity.

Example:
- Jug A capacity: 4 litres
- Jug B capacity: 3 litres
- Target quantity: 2 litres

## Performance Analysis
- Search strategy: Breadth-First Search (BFS)
- Time complexity: O(V + E) for the explored state graph
- Space complexity: O(V)
- Execution time: To be measured during execution
